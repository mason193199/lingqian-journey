# 《靈籤小旅》

可愛奇幻 × 東方玄學的 2D 橫向動作 Roguelite。第一章「靈霧竹林」為可從開始到通關的短篇 MVP，使用原創 Canvas 程序繪圖，不需外部圖片、字型、帳號、API 金鑰或後端。

## 免安裝試玩

`npm run build` 會額外產生完全獨立的 `dist/lingqian-journey.html`。下載這個 HTML 檔，用 Chrome、Edge 或 Firefox 直接開啟即可遊玩，不需要 Node.js、伺服器或網路。已驗證獨立 HTML 的開始、鍵盤操作與暫停；本雲端瀏覽器政策禁止 `file://`，因此檔案模式尚待一般電腦實測。手機建議將檔案放至靜態網站主機後用網址開啟，避免手機系統的檔案預覽器限制 JavaScript。

## 執行

需 Node.js 20.19+ 或 22.12+（本環境使用 24），npm。

```sh
npm ci
npm run dev -- --port 5173
```

在執行機器的瀏覽器開啟開發伺服器。手機可透過同網路可達的主機位址遊玩；建議橫向，支援同時移動、攻擊及跳躍。雲端的外部存取需使用平台提供的連接埠轉送功能。建置部署：`npm run build`，將 `dist/` 發佈至任何靜態網站主機即可。

## 操作

| 動作 | 鍵盤 | 手機 |
|---|---|---|
| 左右移動 | A / D 或 ← / → | 左下方向鍵 |
| 跳躍 | Space / W / ↑ | 躍 |
| 普通攻擊 | J / Z，支援按住連續攻擊 | 符，支援按住 |
| 衝刺 | K / X / Shift | 衝 |
| 暫停 | Esc / P | 右上暫停 |

衝刺有短暫無敵與冷卻。受傷後有一秒保護。切換視窗會自動暫停；音效預設關閉，右上可開啟。

## 一段完整旅程

小旅人帶著靈符與羅盤，循星燈進入竹林，淨化受霧咒影響的妖靈。

1. 面對兩隻有突進前搖的近戰霧團，學習移動與攻擊。
2. 保證觸發一次三選一命籤，回復 25 生命：離火攻擊 +40%、青木生命上限 +30 並額外回復 30、巽風速度 +15% 與縮短衝刺冷卻。
3. 面對近戰霧團與發射靈彈的遠程燈妖。
4. 回復 20 生命，迎戰竹魄守。重擊顯示地面警告，衝撞長時間蓄勢，半血加入三向靈彈。重擊可跳躍躲避，衝刺可穿過傷害。
5. 淨化 Boss 進入通關畫面；死亡或通關皆可重新開始，所有能力與戰鬥狀態重設。

## 驗證

```sh
npm test
npm run build
npm run test:e2e
```

57 項模型測試與 24 項 Playwright 瀏覽器情境（含真實鍵盤通關、三種祝福完整流程及手機多指觸控）。瀏覽器測試預設使用本環境 `/usr/bin/chromium`，其他環境可用 `CHROMIUM_PATH` 指定已安裝的 Chromium。不需要在一般遊玩時安裝測試瀏覽器。

完整流程的自動化測試使用正常能力和遊戲輸入模型加速執行；UI 狀態測試會使用測試介面直接設定戰鬥情境。只有網址帶 `?test` 才會公開 `window.__game` 診斷介面。

## 結構

- `src/game.js`：不依賴 DOM 的戰鬥與關卡狀態。
- `src/render.js`：竹林、角色、妖靈、八卦祭壇與招式特效。
- `src/main.js`：鍵盤、多點觸控、介面、音效與遊戲循環。
- `index.html`、`style.css`：繁中介面與響應式排版。
- `tests/`：模型與瀏覽器測試。

## MVP 範圍

單章、六角色、三武器、兩種小怪、一名 Boss、五種命籤。已加入輕度永久成長與本地存檔；隨機地形與多章節尚未加入，目前為手工安排的短章節。圖像為程序繪圖，音效為簡單合成提示音。瀏覽器模擬手機已驗證，實體 iOS / Android 與 Safari 仍需實機測試。後續優先調整戰鬥節奏、Boss 壓力與行動裝置手感，再擴充內容。

## GitHub Pages 免費部署

正式網站預定網址：`https://mason193199.github.io/lingqian-journey/`。

`vite.config.js` 使用相對資源路徑，支援 GitHub Pages 的專案子路徑。已用靜態伺服器在 `/lingqian-journey/` 實測正式建置的桌面鍵盤、手機橫向觸控、祝福選擇與資源載入。手機驗證使用 Chromium 的 iPhone 螢幕／觸控模擬，非實體 Safari 測試。

首次需要儲存庫管理員在 **Settings → Pages → Build and deployment** 選 **Deploy from a branch**、**gh-pages**、**/ (root)**，按 **Save**。若已設定好則不需重複。GitHub 會自行完成 HTTPS 發佈。

維護者更新方式（需該儲存庫 Git 推送權限）：

```sh
npm ci
npm test
npm run build
npm run test:production
# 先將已驗證的原始碼 commit 至 main，再發佈：
npm run deploy:pages
```

`deploy:pages` 僅將 `dist/` 發佈到 `gh-pages`，不更動工作目錄，也不強制覆寫分支歷史；沒有後端、金鑰或付費服務。部署分支含 `.nojekyll` 與 `version.json` 供驗證來源版本。上傳分支不代表 Pages 設定已啟用或網站已公開，必須另行檢查實際網址。


## 像素靈境美術更新

第一章採 640×360 低解析度畫布，以 nearest-neighbor 放大呈現一致像素風；戰鬥座標、碰撞箱、傷害、敵人 AI、祝福效果與通關流程保留。場景增加多層遠山、竹林、霧帶、石燈、符紙、苔蘚磚地與八卦祭壇；主角、霧團、燈妖與竹魄守使用一致配色的像素外觀。

特效包含符光拖尾、命中碎光、0.13 秒敵人閃白、傷害數字、衝刺殘影、祝福儀式與確認提示、Boss 招式預警與淨化收尾。Boss 死亡立即判勝並清除危險物，先播放0.85秒收尾再顯示通關介面。視覺事件最多48個並自動清除，圖像使用快取；減少動態效果設定會減少粒子與裝飾動態。HUD 僅在數值改變時更新。

這輪也修正短按攻擊可能發生在兩個畫格之間而漏接的問題，以及暫停後觸控按鈕按壓樣式殘留。視覺計時與模擬分離，暫停不推進戰鬥或特效。桌面 Chromium 與手機橫向觸控模擬、直向排版、完整鍵盤通關及 GitHub Pages 子路徑正式版均列入測試；尚未以實體 iOS Safari 驗證。


## 橫向與局外成長更新

手機直向顯示旋轉提示、暫停進行中的戰鬥；旋轉回橫向後可手動繼續。橫向使用完整可視區域與 safe-area，支援瀏覽器網址列尺寸變更；方向鎖定與全螢幕均為可選增強功能，不支援時提供手動旋轉提示。PWA manifest 偏好 landscape，但未加入離線 service worker。

開始畫面 → 行前準備 → 三武器選擇與修行 → 開始冒險。桃木劍22傷害/.34秒/115距離，強擊退與破甲；靈符18/.42秒/560距離，投射符紙與燃燒；星紋靈杖32/.72秒/440距離，每發15靈力、緩慢追蹤與範圍傷害、冰緩雷感，每第三發短暫冰凍。靈力每秒回復12。各武器有獨立暴擊率、暴傷、元素、稀有度與攻擊聲音。暴擊以累積率平均觸發，雷感連鎖以35%機率觸發。

共用狀態系統支援燃燒、冰緩、冰凍、中毒（最多3層）、雷感、破甲、護盾與霸體；Boss 有持續時間、控制與擊退抗性。冰凍結束有控制免疫空窗。玩家受擊後約1秒無敵、短硬直及可見擊退；短暫hit-stop與低幅度震動僅作戰鬥回饋。

靈玉於死亡／通關結算：每隻妖靈2、Boss額外10、首次通關額外10。同一局不重複領取。生命修行上限5級（每級+4生命）、靈力3級（每級+10容量）、各武器精通3級（每級+3%傷害），命格與法器各1級解鎖護盾／霸體及生命／靈力開局配置。

存檔為此瀏覽器、此網站的 localStorage，含版本、備份、資料檢查、有限歷史結算ID與設定。重新整理不會重置局外資料；不保存進行中的關卡。清除網站資料／無痕模式／更換裝置不會共享存檔。瀏覽器拒絕儲存時仍能遊玩，準備畫面會提示無法存檔；沒有雲端同步。`?test` 額外暴露 `__meta`，並保留舊測試直接開始的捷徑，正常網址必定經過行前準備。

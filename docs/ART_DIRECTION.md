# 《靈籤小旅》像素美術規範 · v0.5

這份規範約束第一章的品質改善，不宣稱已完成整套商業級角色逐幀素材。圖像繼續使用本專案原創程序像素繪製，不引入來源不明的網路素材。

## 像素與輪廓

- 戰鬥邏輯座標為1280×720；世界先畫到640×360，再 nearest-neighbour 放大。基本輪廓使用2個邏輯單位＝1個原生像素；美術改動不得改碰撞框。
- 旅人基礎像素立繪24×26；明暗以相鄰色塊成組處理，不使用細碎照片紋理。普通小妖約24×17／24×22；Boss含竹角約55×84，維持明顯體量差。
- 旅人維持深色輪廓、暖膚色、淺內襟、明確武器。六角色以衣色與可讀配件共同區分：阿籤籤囊、青嶽頭帶與劍鞘、紅綾繫帶、星漣星冠、白璃靈耳披肩、玄墨肩甲與鎮印。
- 武器必須畫在握持點上；劍身與護手、符紙朱文、靈杖晶頭各有專屬輪廓。攻擊動畫不以單一模糊光團替代武器。

## 色彩與層次

| 用途 | 主色／規則 |
| --- | --- |
| 輪廓與深影 | #263644、#192f40；避免全黑硬邊壓過柔和角色 |
| 竹林 | 遠山紫灰→遠竹青灰→近竹深綠；近景對比高於遠景 |
| 靈氣 | 淺翡翠#c2e6bd；低透明度，不與傷害預警混用 |
| 紙燈與靈符 | 暖紙黃#f3d797／#ffe1a0，搭配低彩朱砂 |
| 敵人危險 | 玫紅／暖橘預兆與明確範圍線；背景裝飾不能模仿預警 |
| 命中重點 | 短白閃、金色暴擊；不以大面積持續全屏閃爍表現 |

背景保留多層山、竹、霧、地磚與石燈；v0.5新增遠祠剪影、紙燈籠、較尖細的竹葉簇、低頻竹枝擺動與少量落葉。所有裝飾都只是畫面內容，不是可碰撞平台、隱藏寶箱或可互動NPC。

## 動作與特效

- 旅人使用固定五組姿態：站立、兩個移動腳步、上升、下落。姿態快取只使用這些有限鍵，不依每幀時間建立新圖像。
- 移動腳步約10次切換／秒；碰撞、跳躍與攻擊仍以原模擬更新。背景僅2Hz手機／4Hz桌面快取更新，low降為1Hz，絕不降低敵人攻擊與預警的更新頻率。
- 靈杖讀取`castTime/maxCastTime`，握杖後收與小型靈環／像素進度條對應真實0.16秒蓄力；low仍保留進度，減少動態仍保留必要施法提示。落地讀取`landingTime`，最多7%輕微壓縮與2～6粒地面塵點，不改角色座標。
- 霧團蓄力時壓縮、突進時微伸；符靈有燈面高光；Boss細化面具、衣褶與衣襬，但紅色地面預警、文字與實際危險區域不變。
- 六角色技能使用既有事件生命期增加對應圖騰：八卦、劍痕、飛符、北斗點、靈獸爪印、山印。不新增傷害或機制，不另產生持續堆疊的特效物件。
- 技能與進化仍受既有事件上限48、召喚3、冰陣3等限制；手機auto只畫最近24個視覺事件、最近10個傷害／互動文字。背景裝飾不遮擋角色或敵人。

## 可調整品質與可讀性

`render(output, game, time)` 讀取 `game.presentation`，不改既有API：

- `effectsQuality`: auto沿用手機／桌面預算；low減少事件、粒子、傷害文字、裝飾與背景更新；high可繪更多既有事件，物件建立上限不變。
- `reducedMotion`: 與系統偏好合併；停用閃避震動、裝飾漂移、角色上下擺動與落葉，保留必要戰鬥移動、範圍與攻擊提示。
- `shakeIntensity`: 0～1，0完全取消鏡頭位移；數值不合法時回復既有預設。
- `damageText`: false時隱藏純數值傷害與「暴擊 N」，保留靈錢、破勢、淨化等互動提示。

質量／減少動態會加入背景快取鍵，設定切換即重新繪製背景。字型保持瀏覽器系統中文字體和遊戲既有monospace數字，優先可讀性；不下載外部字型。

## 原創與來源

本次新增竹葉、紙燈、遠祠、衣紋、配件、腳步姿態與技能圖騰，均由本專案程式逐像素自繪。沒有新增第三方圖片、音樂、字型或素材包，也沒有新的素材授權依賴。沿用圖像同樣在 `src/render.js` 內，來源與修改均可由Git歷史追溯；本文件不額外替整個repository宣告新的授權條款。

## 尚未完成／後續品質工作

目前仍以共用旅人基礎像素胴體加配色與配件為主，不是六套完整獨立骨架／逐幀動畫。NPC立繪、各角色情緒表情、Boss額外變體、敘事插畫與完整音樂留待對應版本；不得把背景遠祠稱為可探索地形。本環境只能用Chromium繪圖與手機尺寸模擬，沒有實體iPhone／Android視覺或FPS驗證。

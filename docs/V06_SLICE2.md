# v0.6.1 — 自選單房天劫

接續72b4108；保留v0.6首切片、原公開版本與原本八種房間，不重建核心玩法。

## 玩家真正新增的選擇

正式冒險的精英房入場後先暫停。可以選兩種天劫，或不付任何額外代價開始原精英戰。選項明示風險／報酬，不在選路時暗中套用。拒絕後的敵人、血量、傷害、掉落與原精英戰一致。

- 五雷試心：第一次約入場3秒後落雷，之後每4秒一次。先在玩家當下位置標記112px雷區，0.95秒前搖；標記後不追蹤。移出、跳高110px或用正常衝刺無敵躲避；包含命中同幀按衝刺。落雷12基礎傷害仍遵守原有護盾／受擊無敵／交易傷害規則。成功額外18靈錢＋稀有法器三選一。
- 封靈試心：開戰4秒不能用天賦技能，按鈕顯示倒數；自然回靈為35%，天賦技能冷卻恢復為60%。其他角色計時、召喚物、祝福與基本攻擊不被一起減速。成功額外10靈錢＋珍奇法器三選一。
- 若全法器已達獎勵品質，改給12靈錢；所有貨幣仍上限999，沒有重複領取／無限商店資源。

這讓玩家能依Build選擇「維持開場爆發但要躲雷」或「延後天賦、以武器撐過開場」，也可以為保命完全拒絕。不是三把武器一律加傷害。

## 保護與架構

`src/trials.js`集中資料／平衡參數／單房狀態機。trial綁roomId，offered→active/declined→completed。不改永久數值與localStorage schema，不保存進行中Run；重新整理仍回到原局外存檔。

有限迷霧／命籤等configureCombat只在決策後消耗一次。勝利先完成原清房與出口，再顯示法器選擇；確認後回到已產生的三條路。換房清空trial，Boss及新Run不繼承限制。完成旗標先寫再發獎；事件守墓精英仍走原流程，不插入天劫。

警告直接畫在遊戲世界，無額外高頻粒子或無上限陣列；最多一個雷區。減少動態／低品質不會隱藏危險範圍。手機卡片可捲動，接受／拒絕沿用原生按鈕與清除戰鬥輸入。新UI只有真實功能。

## QA發現與修正

1. 第一版封靈只有恢復減速，36組模擬顯示短戰鬥實際無代價；加入4秒起手封技並接入實際技能出口／按鈕倒數。修正後54組含拒絕的實際戰鬥控制器皆過，封靈首次技能在約4.033秒，並非只改文案。
2. 第一版雷判定在輸入前，命中幀按衝刺可能失敗；移到玩家移動／衝刺之後，新增同幀回歸。
3. 新正式入口瀏覽器測試起初未開診斷網址，無法讀到刻意只在test暴露的模型；改走test→真正行前準備→正式Run，不增加公開除錯全域。

完整驗收：148/148模型測試（內含54組戰鬥與36組完整種子路線）、59/59 Chromium瀏覽器情境；最後版本標籤更新後再重跑8個天劫／原生手勢情境通過。Production build、desktop與iPhone尺寸子路徑／新正式天劫獎勵流程、獨立HTML、diff check通過。部署來源以AI_HANDOFF最新記錄為準。

## 實測限制與下個切片

Chromium手機尺寸／CDP多指與CPU降速不等於實體Safari、Android或Edge品牌測試。實體手機縮放修補仍待使用者新回饋，不能因這次天劫測試宣稱全部實機通過。

獨立控制器54組全部能過，但不是人類公平性證明；封靈依角色與開場站位未必更慢，阿籤等工具角色受影響較小。稀有／珍奇報酬應繼續看人類選擇率，必要時下調，不能用自動戰鬥時間當唯一平衡結論。

本切片未做：平台／秘密探索、血契與完整天劫組合、Boss變體、第二章、v0.7劇情等。下一切片先加入少量可讀地形與一次性探索，避免整版同時半成品。

# v0.6.0 — 第一個可玩切片（2026-10-28）

本次完成手機原生縮放修補後，接續Boss攻防與Build成形切片；不宣稱完整v0.6的地形／天劫／角色挑戰已完成。

## 手機緊急修補

使用者確認「左右移動＋攻擊等多指操作」會意外放大。獨立hit-test確認Canvas因world-layer指標透明，實際命中game-shell；原先只有Canvas touch-action不能保護整個戰鬥區。

v0.5.1 checkpoint304827b已先整合main並部署（gh-pages sourceCommit已核對），再接續本切片。防護包含實際戰鬥容器touch-action:none、選單pan-y、element-scoped非passive多指touch與Safari gesture取消、快速touchend fallback、16px表單避免iOS焦點自動放大。原生單擊、單指菜單捲動、遊戲外縮放及全局viewport輔助能力保留。不是僅攔截晚到的dblclick。

新增CDP真實多指移動＋攻擊連按／戰鬥空白雙指展開測試，scale維持1且動作有效、放手不卡鍵；另驗證gesture取消、單指選單／表單及outside不攔截。這是Chromium模擬，使用者尚未確認修補後的實體Safari結果。

## Boss攻防

- 正常冒險啟用encounterV6，Boss仍286生命、原有攻擊傷害；不是只加血量。
- 66%／33%生命門檻觸發兩道守印，先完成兩式清楚前搖攻勢，再開最多2.2秒反擊窗口，窗口傷害×1.18。玩家不必無傷才解印，避免初學者永久卡關。
- 守印有短期抗控，不能無限冰凍／輕擊硬直卡住；既有跳躍／衝刺可應對招式。護印文字、符紙、像素光圈與反擊提示實際反映狀態。
- Boss房固定可視場地、可讀左界；玩家／Boss／追加敵人夾限一致，左右撞牆雷爆一致。新參數集中src/boss-encounter.js。
- 舊診斷／模型未指定新模式時保留經驗證的經典Boss，避免把歷史guardrail悄悄換成另一個測試。

## Build與抉擇

- 正常冒險啟用buildV6：初始命籤以種子抽取，不強塞匹配武器祝福。命籤只定五行，不同時免費給卦象。
- 祭壇每次只調五行或卦象一項，顯示預覽、只啟用對應欄位；同值／無效slot／繼承ID拒絕、不消耗使用次數。
- 兩次祭壇可補完任一三武器配方，代價是放棄同層法器／恢復／事件；有限角色／命格重抽仍保留。並非每局只能靠運氣成形。
- 武器架提供八種實際流派指南：條件、法器、強項與弱點。新增第11協同乾元追影：桃木劍＋乾卦＋陰陽玉，有效暴擊後三秒內衝刺追加一次近身影斬與破甲；冷卻1.2秒，有限目標，不能隔樓層命中／遞迴暴擊。與震卦雷劍互斥。
- 換祝福可能改變五行／中斷目前進化，卡片與商店文字提示；HUD顯示影斬蓄能倒數。所有新機制是真實戰鬥效果，未新增假天劫／地形按鈕。

- 137/137模型測試、54/54 Chromium瀏覽器情境全通過。手機Boss字級調整後又通過6個Boss/Build/原生手勢情境。

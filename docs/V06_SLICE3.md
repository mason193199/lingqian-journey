# v0.6.2 — 竹影藏籤：小型地形與秘密探索

日期：2026-10-30。由main3a7cc07續作，使用獨立v06/terrain-secrets分支；保留兩種天劫、三進化、六角色及原有存檔。

## 實際可玩內容

- 非初戰的普通戰鬥房新增兩種種子決定的竹台布局：竹梢石徑、月門竹台。每房2～3座單向平台，可穿過底部跳上，下降時落在平台頂部。
- 完整地面路徑仍連通；不想跳台也可正常打完。平台不作為敵人地面路徑的實體牆；地面霧團較難接近高處，遠程符靈仍朝玩家實際位置發射。桃木劍要回到近身高度，符／杖可由高處施法，並非只給數值加成。
- 上層藏一只符匣；正常登台觸碰可得12局內靈錢，每房一次、貨幣上限999。實際獲得多少顯示多少，不把碰上底部或空中擦過算作收取。符匣與符紙均為原創像素程序圖。
- 清完普通房不再立刻跳轉：清除敵彈、預警與負面狀態，保留護盾／霸體，讓玩家可留下探索或直接離開。有限友方治療仍遵守既有每局額度。按F或手機「下一房」按鈕回到原三選一路線；不需要走到遠端出口，也不強迫找匣。
- HUD提示是否已找匣，旅程分頁記錄本局尋獲數。精英／天劫、事件守墓、初戰與Boss場地不加平台；換房／重開不殘留。

## 架構與風險控制

src/terrain.js集中跳躍／重力／平台／符匣參數與可離開條件；moveVertical共用一個下降掃掠落地出口，groundY供角色呈現與教學使用。落地特效沿用COMBAT_FEEL。無新物理套件、移動平台、坑洞、側牆碰撞或大型重構。

正常冒險顯式啟用terrainV6；診斷與歷史fixture不偷偷更換規則。正式冒險瀏覽器通關控制器已更新成真的點擊「下一房」，不關旗標繞過新流程。F是單次邊緣輸入：在戰鬥中提前按住不會在清場後自動退出。離開驗證ready、roomId與零存活敵人；原clearRoom仍是一次性結算來源，五帝錢等在離開時只結算一次。

平台／符匣屬局內資料，沿用既有「不保存進行中Run」規則，不修改localStorage鍵或schema。永久進度、設定、天賦與歷史回歸仍通過；重新整理會失去目前Run，與先前版本一致。
